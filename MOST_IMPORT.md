# Перенос детей и прогресса из МОСТ

Состояние на 17 сентября 2026 года: формат выгрузки пользователю пока неизвестен.
На публичной странице https://most-montessori.ru/site описаны наблюдения, карты
развития, планирование и отчеты. Инструкции экспорта навыков и публичного API на
этой странице не найдены. Это не означает, что выгрузки или API нет в личном
кабинете или по запросу в поддержку.

В ГлобоАтлас уже существует импорт справочника навыков из Excel. Перенос детей
вместе с их индивидуальными отметками из МОСТ пока не реализован: для него нужен
пример реальных колонок и значений. Прямое подключение к МОСТ не создавалось.

## Что запросить

Можно отправить поддержке МОСТ такой текст:

> Здравствуйте! Нам нужна выгрузка данных нашего сада для переноса в другую
> систему: список детей с внутренними ID, датами рождения и группами; справочник
> навыков/презентаций с ID и иерархией зон; отметки освоения каждого ребенка со
> статусами, датами и комментариями. Нужна связь «ID ребенка — ID навыка».
> Подскажите, доступны ли Excel/CSV/JSON или API, и можно ли выгрузить историю
> изменений прогресса, а не только текущие значения?

Для первой оценки достаточно нескольких строк с вымышленными именами,
сохраненными названиями колонок и примерами всех статусов. Пароли и ключи не нужны.

## Как должен работать импорт после получения примера

1. Загрузка выгрузки и предварительный просмотр без записи в базу.
2. Сопоставление детей и групп по ID источника. Совпадение ФИО само по себе
   недостаточно: возможны тезки и уже зачисленные дети.
3. Сопоставление навыков по ID и иерархии. Одинаковое название в разных зонах
   не означает один и тот же навык.
4. Явная таблица перевода статусов МОСТ в «Не начат», «Знакомство», «Повторение»,
   «Усвоено». Неизвестные значения отправляются на разбор, а не заменяются наугад.
5. Список новых записей, совпадений, конфликтов и ошибок. Пользователь решает,
   какие существующие отметки можно обновить.
6. Подтверждение импорта, журнал результата и защита от повторного переноса
   одного файла/записи. Данные должны попадать в существующую матрицу прогресса
   педагога и карту развития родителя.

Если экспорт содержит только текущие статусы, перенести можно текущее состояние.
Историю и исходные даты, которых нет в выгрузке, восстанавливать предположениями нельзя.
Приглашения родителям не следует рассылать автоматически во время импорта.
