# Календарь, навигация и чаты — 17 сентября 2026 года

## Навигация

Боковое меню перенесено в постоянную оболочку приложения на уровне корневого
layout. Раньше каждое переключение страницы заново создавало меню с пустым списком
модулей, а после запроса добавляло табель и календари. Теперь состояние и положение
прокрутки сохраняются между страницами. При выходе или смене пользователя/роли
состояние меню сбрасывается. Добавлен резерв места под вертикальную полосу прокрутки.

## Один календарь

- В меню один пункт «Календарь».
- Фильтры «Все», «Личные», «Общие» находятся внутри страницы.
- Личные события отмечены фиолетовым цветом, общие — бирюзовым. Также есть текстовые подписи.
- При создании и редактировании выбирается «Личное — я и выбранные участники»
  или «Общее — вся команда».
- Личный фильтр показывает закрытые события автора и его приглашения. Общий
  фильтр показывает только события для всей команды. В режиме «Все» руководство
  видит также остальные закрытые события; обычный сотрудник чужие закрытые встречи не получает.
- Старая ссылка `/team/calendar/personal` перенаправляет в календарь с личным фильтром.

Записи календаря не пересоздаются и не теряются. Расписание занятий и приемы
специалистов остаются в существующих разделах.

## Чаты сотрудников

Педагог, психолог и педиатр могут выбрать коллегу через «Чаты → Новый чат».
Коллеги доступны даже если педагог пока не назначен на группу. Администратору,
директору, суперадминистратору, методисту и менеджеру продаж тоже добавлен раздел
чатов. Это личные диалоги сотрудников; групповые комнаты этим обновлением не добавлялись.

Выбор родителей у педагогов и специалистов сохраняет существующие связи с детьми.
Родителям не открывается общий каталог сотрудников. Заблокированные и удаленные
аккаунты исключены из новых контактов. При создании диалога сервер проверяет
доступность адресата и определяет тип чата по ролям, игнорируя тип из старых клиентов.
Одновременное создание диалога одной парой сотрудников защищено блокировкой в базе.
Читать сообщения можно только участникам комнаты, включая руководство.

Сообщения сохраняются через HTTP и доставляются через WebSocket. После потери
соединения история дозагружается; открытая вкладка также обновляет сообщения
каждые 10 секунд. Ошибка отправки отображается в интерфейсе, текст и вложения
остаются в поле ввода. Прокрутка сообщений ограничена областью переписки.

## Развертывание

```bash
cd /opt/globoatlas &&
git pull --ff-only origin master &&
bash scripts/update-production.sh
```

Миграция `20260917000000_staff_chats` добавляет тип диалога `staff_staff`.
Существующие переписки, дети и прогресс сохраняются. Скрипт обновления собирает
образы на VPS, делает копию базы и `.env`, применяет миграции и перезапускает портал.

Локальные тесты, сборки и запуск приложения не выполнялись по просьбе пользователя.
Выполнены просмотр исходного кода и форматирование измененных компонентов.
На VPS нужно проверить переходы между страницами, фильтры календаря и обмен
сообщениями из двух отдельных учетных записей педагогов.

Порядок подготовки импорта МОСТ описан в [MOST_IMPORT.md](MOST_IMPORT.md).
