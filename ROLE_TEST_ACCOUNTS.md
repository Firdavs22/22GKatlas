# Временные аккаунты для проверки ролей

Это обычные пользователи основного портала с логином и паролем, которые задает
оператор VPS. Отдельной демобазы, дополнительных детей и публичной кнопки входа нет.
Войти может каждый, кому переданы эти данные. Аккаунты получают обычные права роли,
включая доступ к реальным данным, поэтому это не изолированный публичный демостенд.

## Создать аккаунт на VPS

Выполнить в SSH-терминале:

```bash
cd /opt/globoatlas &&
git pull --ff-only origin master &&
bash scripts/create-role-account.sh
```

Команда предложит выбрать роль, ввести email, имя, пароль и повторить пароль.
При вводе пароля символы не отображаются. Минимум 8 символов, максимум 72 байта.

| Номер | Роль |
| --- | --- |
| 1 | Педагог |
| 2 | Родитель |
| 3 | Психолог |
| 4 | Педиатр |
| 5 | Методист |
| 6 | Менеджер продаж |
| 7 | Администратор |
| 8 | Директор |

Например, для педиатра выбрать **4**, указать `pediatr@test.ru` и свой пароль.
После сообщения об успешном создании войти через https://lk.globokids.ru/login.
Для следующего аккаунта снова выполнить `bash scripts/create-role-account.sh`.

Письма не отправляются, SMTP не требуется. Создание не добавляет согласие на
обработку данных от имени пользователя. Пароль хранится в базе только как bcrypt-хеш,
не сохраняется в скрипте и не выводится в журнал. Событие создания записывается в аудит
без email и пароля. Используйте эту команду для временной проверки; приглашения
настоящих сотрудников и родителей остаются в интерфейсе портала.

Повторный запуск с занятым email завершится без изменения существующего аккаунта.
Суперадминистратора этой командой создать нельзя.

Новые миграции и пересборка для самого скрипта не нужны: файл подключается к одноразовому
контейнеру backend. База должна быть запущена, а образ backend и миграции — поддерживать
выбранную роль. Если установлена старая версия портала, сначала выполните обычное
обновление `bash scripts/update-production.sh`.

## Что будет видно

Педагогу нужно назначить группу в разделе «Группы». Родителю нужно привязать ребенка
в разделе «Родители». Без этих связей их списки детей будут пустыми. Психолог, педиатр,
администратор и директор имеют более широкий доступ в соответствии с текущими правилами
портала. Создание аккаунта не меняет эти правила.

Проверять разные роли удобно в разных профилях браузера. Несколько вкладок одного
профиля используют одну сессию. Частые входы с одного IP могут попасть под существующее
ограничение: 5 запросов входа за 15 минут; скрипт создания не отключает защиту.

## Отключить или удалить после проверки

Войти суперадминистратором:

- сотрудники, включая директора: «Сотрудники» → нужный аккаунт → «Заблокировать»
  или «Удалить»;
- родитель: «Родители» → нужный аккаунт → «Заблокировать» или «Удалить».

Удаление аккаунта в интерфейсе убирает доступ и анонимизирует его данные. Связанные
записи сохраняются для целостности истории. Действия, выполненные пользователем
в рабочих данных, автоматически не отменяются.

## Мобильное приложение

В `mobile/` есть исходники Expo / React Native для Android и iOS. В репозитории нет
готовых APK/IPA и `eas.json`. Адрес сервера в `mobile/app.json` уже указывает на
`https://lk.globokids.ru`. Наличие исходников не подтверждает готовность установленного
приложения: сборку и работу на устройствах в рамках этого изменения не проверяли.

Есть экраны родителя, педагога и специалистов. Новые веб-разделы перенесены не полностью:
у методиста пока ссылка на веб-портал, роль менеджера продаж отсутствует в мобильных типах,
нет отдельных мобильных экранов CRM, табеля и календаря команды. Для проверки всех
текущих ролей используйте портал в браузере, в том числе на телефоне.
