## 🔮 Долгий хвост (после запуска)

### Storage
- **Миграция MinIO → Selectel S3** — MinIO Inc архивировали open-source с конца 2025. Через 6-12 мес security-патчей не будет. Перевод — поменять 3 переменные в `.env`, API S3-совместим.

### UX / Onboarding
- **Onboarding-мастер для админа** — после первого логина: имя сада, лого, первая группа, первый педагог. Сейчас попадает в пустой `/admin` без подсказок.
- **Empty states** — иллюстрации + CTA на пустых страницах (нет постов, нет задач, нет детей).
- **KB-контент** — наполнить базу знаний для родителей: «Зоны Монтессори», «Стадии освоения», FAQ.

### Compliance
- **Архивирование старых данных** — через 3 года после выпуска ребёнка обезличивать ПДн (152-ФЗ). Cron-скрипт.
- **MFA для админа** — TOTP через `otplib`. Для 500 юзеров желательно.
- **2-факторка для админа** — для повышенной защиты единого админ-аккаунта.

### Performance (при росте > 500 юзеров)
- **PgBouncer** — connection pooling для Postgres (на 1000+ юзеров)
- **Read-replica** — для Postgres (2000+ юзеров)
- **CDN для медиа** — Yandex Object Storage с CDN, либо переход на Selectel CDN

## 🎯 Рекомендуемый порядок

Если работать только над **критическим путём к запуску**, оптимальная последовательность:

```
DTO для остальных endpoints      (3-4 ч)   ← быстрый win, "зеленит" security
       ↓
MIME-валидация + rate limit       (2 ч)    ← быстрые wins
       ↓
Data export                       (1 день) ← юр. требование
       ↓
JWT httpOnly cookies + CSRF       (1-2 дня) ← главная защита
       ↓
Mobile: forgot/reset + feed/[id]   (1 день) ← UX
       ↓
[опционально] MFA, Selectel S3, onboarding-мастер
```

Параллельно (не блокирует разработку):
- Регистрация оператора ПДн (30 дней ожидания)
- Договор оператора с садом
- Текст privacy с юристом

**Минимальный путь до пилота на 5-10 садов:** ~1 неделя кода + 30 дней Роскомнадзора = ~5 недель.
